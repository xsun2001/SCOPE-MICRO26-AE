# Source provenance

This directory contains the shared trainer used by Figures 17 and 20 and the SCNA side of Table 4. It began from parent commit `20b562040e1d07c888b1c1e3efbedc6f71048453` and now includes the corrected split between reciprocal square root (`rsqrt`, whose default Table 4 protocol evaluates `1 / sqrt(-x)` on `[-1024, -0.1]` with `lambda_bound=0.10`) and reciprocal (`recip`, evaluated as `-(1 / x)` on `[-16, -1]`). The Figure 17/20 workers explicitly retain their archived `[-256, -1]`, `lambda_bound=0.15` ablation protocol. The `baselines/` directory and Taylor diagnostic preserve the partial Table 4 baseline implementations found under the same workspace source directory.
