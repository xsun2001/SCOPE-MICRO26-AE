# Source provenance

This directory contains the relevant subset of the workspace's top-level `train/` source directory. `train.py` is the historical paper snapshot shared by Figures 17 and 20 and the available SCNA side of Table 4. It comes from parent commit `20b562040e1d07c888b1c1e3efbedc6f71048453` (SHA-256 `8aa2816d76343b3ae294fbc80da03f51e617c8e78da13c0c9b90ab8237a5010a`). Later Rsqrt/Recip trainer changes are intentionally excluded. The `baselines/` directory and Taylor diagnostic preserve the partial Table 4 implementations found under the same workspace source directory; they are not a claim that the missing unified Table 4 protocol can be reconstructed.
